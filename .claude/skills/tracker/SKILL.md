# tracker

## Назначение

`tracker` — обёртка над скиллом `extract-price` для пакетного обхода
списка отслеживаемых товаров. Сейчас реализует только сбор таблицы цен за
один прогон. В будущем сюда добавятся:

- персистентное хранение истории прогонов (снэпшоты по датам);
- diff цен и `has_credit` между текущим и предыдущим прогоном;
- отправка уведомлений об изменениях в Telegram.

Пока этого нет — `tracker` только обходит список и строит таблицу текущего
прогона.

ручного перечисления ссылок при каждом вызове.

(и только его) — остальная часть скилла не меняется.

## Сценарий выполнения

`tracker` не парсит цены сам — вся эта логика уже инкапсулирована в скилле
`extract-price`, и `tracker` её не дублирует, а переиспользует.

Для каждого URL из списка выше, по порядку:

1. Вызови скилл `extract-price`, передав ему этот URL как единственный
   вход.
2. Получи от него объект `{ regular_price, sale_price, has_credit }`.
3. Добавь строку в итоговую таблицу прогона: URL + три поля из ответа
   `extract-price`, как есть, без изменений и пересчётов.

Обработай так весь список целиком за один запуск и верни одну общую
таблицу по всем товарам — не отдавай результат по одному товару за раз и
не останавливайся на первом.

Если `extract-price` для какого-то URL вернул `null`-объект (страница
недоступна, цена не найдена и т.п.) — зафиксируй это как есть в строке
этого товара и продолжи обход остальных URL из списка. Один неудачный URL
не должен прерывать весь прогон.

## Формат результата (таблица прогона)

Одна строка таблицы = один товар. Колонки: `url`, `regular_price`,
`sale_price`, `has_credit`. Это и есть запись прогона — в будущем именно
такие таблицы будут сохраняться, сравниваться между собой (diff) и
использоваться как источник для уведомлений в Telegram.

Пример формата ответа:

| url | regular_price | sale_price | has_credit |
|---|---|---|---|
| .../76790/... | 13500 | null | true |
| .../76835/... | 2590 | null | true |
| .../56363/... | 12900 | null | true |

## Что не входит в этот скилл (зарезервировано на будущее)

- Хранение истории прогонов.
- Diff цен/наличия рассрочки между прогонами.
- Отправка изменений в Telegram.
